# Tank Troublemaker 💥Un dinámico y divertido juego arcade 2D de batallas de tanques para navegador, desarrollado completamente con HTML5, CSS y JavaScript puro utilizando la API de Canvas. Enfréntate a un amigo en modo local o desafía a la Inteligencia Artificial (CPU) en mapas cerrados donde los proyectiles rebotan y la estrategia es clave.   🎮 Características PrincipalesSin dependencias: Todo el juego está contenido en un único archivo index.html. No requiere librerías externas ni motores de juego.   Balas Rebotadoras: Los proyectiles pueden rebotar en las paredes de acero hasta 4 veces antes de desaparecer. ¡Cuidado con el fuego amigo!   Entornos Interactivos: Los mapas incluyen paredes de acero indestructibles y paredes de ladrillo destructibles que requieren 3 impactos para romperse.   Game Feel Mejorado ("Juice"): El juego cuenta con efectos visuales pulidos como retroceso de cámara (screen shake), retroceso del tanque al disparar, destellos de cañón (muzzle flash), partículas de explosiones, rastros de balas y huellas dinámicas de las orugas en el suelo.   Audio Sintetizado: Efectos de sonido generados en tiempo real mediante la Web Audio API, con variaciones de tono dinámicas para evitar la monotonía.   Inteligencia Artificial Integrada: La CPU cuenta con un sistema de seguimiento del jugador, predicción básica y un sistema de evasión "anti-atascos" si choca contra las paredes.   Sistema de Partidas: El primer jugador en ganar 5 rondas se corona como el campeón.   🕹️ ControlesAcciónJugador 1 (Azul)Jugador 2 / CPU (Rojo)Avanzar / RetrocederW / S   ↑ / ↓   Girar Izquierda / DerechaA / D   ← / →   DispararESPACIO   ENTER o M   Controles Globales:F: Alternar entre el modo "2 Jugadores" y "Jugador VS CPU" (solo en el menú).
